O **1Byte Labs Transmitter 0.5.0 Beta** traz novas interfaces para o Transmitter e o Receiver, além de uma tela virtual opcional. Use a tela virtual para enviar os slides do PowerPoint enquanto mantém suas anotações no monitor físico.

## O que mudou

- **Transmitter:** interface compacta com fonte, acesso e privacidade na janela principal. **Ver prévia** abre uma janela separada quando você precisar conferir a imagem.
- **Receiver:** prévia maior, com a conexão NDI e a saída para o telão em painéis separados. Novo filtro ao redimensionar a imagem na prévia e na saída.
- **Tela virtual:** instale, ative, desative, repare ou desinstale o driver direto pelo Transmitter. A opção **Desativar tela virtual ao sair** vem marcada; o aplicativo tenta restaurar a tela ao reabrir.
- **Barra de tarefas:** minimizar ou usar **Win + D** mantém o Transmitter acessível. O **X** encerra o programa.
- Continuam disponíveis o envio de vídeo e áudio por NDI, a captura de monitor ou janela, os modos **Protegido** e **Rápido** e o controle de privacidade.

## Qual arquivo baixar?

| Arquivo | Quando usar |
| --- | --- |
| **1ByteLabs-Transmitter-v0.5.0-beta-Setup-Windows-x64.exe** | Para instalar o Transmitter no Windows. O driver de tela virtual é opcional. |
| **1ByteLabs-Transmitter-v0.5.0-beta-Windows-x64.zip** | Para usar o Transmitter portable. Extraia o ZIP completo antes de abrir o executável. |
| **1ByteLabs-Receiver-v0.5.0-beta-Windows-x64.zip** | Para receber o sinal no computador do telão. Extraia o ZIP completo e abra o Receiver. |

**Requisitos:** Windows 10 ou 11 x64. Para o uso em dois computadores, conecte ambos à mesma rede local. Os ZIPs já incluem a DLL do NDI; mantenha-a na pasta do executável. Não é preciso instalar o pacote completo do NDI Tools.

## Como transmitir e receber

1. No computador de origem, abra o **Transmitter**, escolha **Monitor** ou **Janela**, selecione a fonte e clique em **Iniciar transmissão**. Deixe **Enviar áudio** marcado se quiser enviar o som do Windows.
2. No computador do telão, abra o **Receiver**, clique em **Atualizar** se necessário, selecione a fonte NDI e clique em **Conectar**.
3. Se estiver usando o modo **Protegido**, volte ao Transmitter e clique em **Liberar transmissão** após detectar o receptor.
4. No Receiver, escolha o monitor de saída e clique em **Exibir telão**. Pressione **Esc** para sair da exibição em tela cheia.

## Como usar a tela virtual no PowerPoint

1. No Transmitter, abra **Configurar tela virtual → Instalar driver**, se ainda não tiver o driver. O Windows pode solicitar autorização de administrador. Se a tela já funciona, não precisa reinstalar.
2. Ative a tela virtual e selecione no Transmitter a entrada **Monitor** marcada como **(virtual)**.
3. No PowerPoint, envie a apresentação para o monitor virtual e use o **Modo de Exibição do Apresentador** no monitor físico para acompanhar suas anotações.
4. Se a tela deixar de aparecer, tente **Ativar tela virtual** ou **Reparar driver** no mesmo painel. Para removê-la do Windows, use **Desinstalar driver**. Remover apenas o aplicativo preserva o driver.

## Dicas e suporte

- **A fonte não apareceu?** Confira se o Transmitter está enviando, se os dois computadores estão na mesma rede e se o aplicativo está permitido no perfil de rede em uso no Firewall do Windows. Depois, atualize a lista de fontes no Receiver.
- **O texto está pouco nítido no telão?** Confira no rodapé do Receiver a resolução recebida. Para um telão Full HD, prefira uma fonte em **1920 × 1080**. Aumentar o FPS melhora a fluidez, mas não recupera detalhe perdido ao ampliar uma fonte menor.
- O driver de tela virtual é opcional e é fornecido pelo projeto **VirtualDrivers**. Os avisos de terceiros e a licença acompanham os pacotes.
